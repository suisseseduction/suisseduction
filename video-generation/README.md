# Suisseduction Video Generation

This directory contains scripts and generated videos for Suisseduction.

## Generated Videos

1. **suisseduction-ultra-simple.mp4** (25 seconds)
   - Pure color-based graphic design video
   - Uses exact brand colors from the website
   - No screenshots or text
   - Perfect for background loops, social media, etc.

2. **suisseduction-basic-video.mp4** (15 seconds)
   - Basic color sections (no text)
   - Shorter version

3. **suisseduction-video.mp4** (from screenshots)
   - Original video with website screenshots
   - Longer format (~50 seconds)

## How to Use

The ultra-simple video is ready to use as-is. It's optimized for:
- Social media platforms (Instagram, Facebook, Twitter, LinkedIn)
- Website backgrounds or hero sections
- Presentation intros
- Advertising or promotional content

## Color Scheme Used

- #222222 - Dark background (matches website nav/body)
- #f8f9fa - Light background (matches website sections)
- #ffffff - White (clean sections)
- #ff6b6b - Primary color (matches website text-primary)
- #4ecdc4 - Accent color (complementary teal)

All colors are taken directly from your website's CSS and design.
